# 🚀 飞书多维表格集成配置指南

## 📋 功能概述
网站表单数据将自动提交到飞书多维表格，便于统一管理和跟进客户预约信息。

## 🔧 配置步骤

### 第一步：创建飞书应用

1. **访问飞书开放平台**
   - 打开 https://open.feishu.cn/
   - 使用企业管理员账号登录

2. **创建企业自建应用**
   - 点击"创建应用" → "企业自建应用"
   - 填写应用名称："Zephyr MedTech 网站表单"
   - 填写应用描述："用于收集网站客户预约信息"
   - 上传应用图标（可选）

3. **获取应用凭证**
   - 进入应用详情页 → "凭证与基础信息"
   - 复制以下信息备用：
     - App ID: `cli_xxxxxxxxxxxxxxxx`
     - App Secret: `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### 第二步：创建多维表格

1. **创建新表格**
   - 打开飞书 → 云文档
   - 点击"新建" → "多维表格"
   - 命名为："客户预约信息表"

2. **设置表格字段**
   按照以下格式创建字段：

   | 字段名称 | 字段类型 | 说明 |
   |---------|---------|------|
   | 姓名 | 文本 | 必填 |
   | 公司名称 | 文本 | 必填 |
   | 职位 | 文本 | 可选 |
   | 邮箱 | 文本 | 必填 |
   | 联系电话 | 文本 | 必填 |
   | 感兴趣的服务 | 文本 | 必填 |
   | 需求描述 | 文本 | 可选 |
   | 提交时间 | 文本 | 自动填写 |
   | 处理状态 | 文本 | 默认"待跟进" |

3. **获取表格信息**
   - 打开表格 → 复制浏览器地址栏URL
   - URL格式：`https://xxx.feishu.cn/base/APP_TOKEN?table=TABLE_ID`
   - 提取以下信息：
     - App Token: URL中`base/`后的字符串
     - Table ID: URL中`table=`后的字符串

### 第三步：配置应用权限

1. **开启机器人能力**
   - 进入应用 → "应用能力"
   - 点击"添加应用能力" → "机器人"
   - 配置机器人信息后保存

2. **申请版本发布**
   - 进入"版本管理与发布"
   - 点击"创建版本"
   - 填写版本号和更新说明
   - 提交审核（通常1-2个工作日）

3. **配置权限范围**
   - 进入"权限管理"
   - 申请以下权限：
     - 云文档权限：查看、编辑多维表格
     - 通讯录权限：读取用户基本信息（可选）

### 第四步：配置环境变量

1. **复制配置文件**
   ```bash
   cp .env.local.example .env.local
   ```

2. **填写配置信息**
   ```env
   FEISHU_APP_ID=你的_App_ID
   FEISHU_APP_SECRET=你的_App_Secret
   FEISHU_APP_TOKEN=你的_App_Token
   FEISHU_TABLE_ID=你的_Table_ID
   ```

### 第五步：测试集成

1. **启动开发服务器**
   ```bash
   pnpm dev
   ```

2. **访问表单页面**
   - 打开 http://localhost:3001/demo
   - 填写测试数据并提交

3. **检查飞书表格**
   - 登录飞书查看多维表格
   - 确认数据是否正确录入

## 🔍 常见问题

### Q: 提交失败怎么办？
**A:** 检查以下几点：
- 确认所有环境变量已正确配置
- 检查应用是否已发布并通过审核
- 确认表格字段名称与代码中一致
- 查看浏览器控制台和网络请求日志

### Q: 如何修改表格字段？
**A:** 修改后需要同步更新：
1. `/lib/feishu-api.ts` 中的字段映射
2. 多维表格中的字段名称
3. 重新部署应用

### Q: 数据安全性如何保障？
**A:** 我们采用了以下安全措施：
- 所有API调用在服务端完成，不暴露密钥
- 使用HTTPS加密传输
- 环境变量中存储敏感信息
- 定期轮换API密钥

### Q: 可以自定义通知吗？
**A:** 可以！你可以：
- 配置飞书群组机器人通知
- 设置邮件提醒
- 集成企业微信通知
