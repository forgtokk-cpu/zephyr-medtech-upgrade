# 🤖 飞书群机器人配置指南

## 📋 功能概述
当客户提交预约表单时，系统会自动将客户信息发送到指定的飞书群聊，让团队成员第一时间收到通知并跟进。

## 🔧 配置步骤

### 第一步：创建飞书群机器人

1. **进入目标群聊**
   - 打开飞书 → 进入你要接收通知的群聊
   - 点击右上角的「更多」按钮（三个点）
   - 选择「设置」

2. **添加群机器人**
   - 在设置页面点击「群机器人」
   - 点击「添加机器人」按钮
   - 在机器人列表中选择「自定义机器人」

3. **配置机器人**
   - 设置机器人名称：建议用「客户预约通知」
   - 上传机器人头像（可选）
   - 点击「添加」完成创建

4. **获取Webhook地址**
   - 创建成功后会显示webhook地址
   - 复制地址备用，格式如下：
     ```
     https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxxxxxxxxxxx
     ```
   - ⚠️ **重要**：请妥善保管此地址，不要泄露给无关人员

### 第二步：配置安全设置（可选但推荐）

#### 方案一：IP白名单（推荐）
1. 在机器人设置页面找到「安全设置」
2. 选择「IP白名单」
3. 添加你的服务器IP地址：
   - 本地开发：`127.0.0.1`
   - Vercel部署：需要查看Vercel的IP范围
   - 其他服务器：填写实际公网IP

#### 方案二：签名校验
1. 在机器人设置页面找到「安全设置」
2. 选择「签名校验」
3. 系统会生成一个签名密钥，复制备用
4. 系统会自动生成签名算法，无需手动处理

#### 方案三：关键词过滤
1. 在机器人设置页面找到「安全设置」
2. 选择「自定义关键词」
3. 设置关键词：如「客户预约」、「新订单」等
4. 只有包含这些关键词的消息才会被发送

### 第三步：配置环境变量

1. **复制配置文件**
   ```bash
   cp .env.local.example .env.local
   ```

2. **填写群机器人配置**
   ```env
   # 群机器人webhook地址（必填）
   FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/你的webhook地址

   # 签名密钥（如果启用了签名校验）
   FEISHU_WEBHOOK_SECRET=你的签名密钥
   ```

3. **重启应用**
   ```bash
   pnpm dev
   ```

### 第四步：测试群通知

1. **访问表单页面**
   - 打开 http://localhost:3001/demo

2. **填写测试数据**
   - 姓名：测试用户
   - 公司：测试公司
   - 邮箱：test@example.com
   - 电话：13800138000
   - 服务：选择任意服务
   - 需求：这是一条测试消息

3. **提交表单**
   - 点击「提交预约」
   - 查看飞书群是否收到通知

## 🔍 常见问题

### Q: 群通知发送失败怎么办？
**A:** 检查以下几点：
1. **Webhook地址是否正确**
   - 确认地址完整且未泄露
   - 检查是否有多余的空格或字符

2. **安全设置问题**
   - 检查IP白名单是否包含当前IP
   - 确认签名校验密钥是否正确
   - 验证关键词是否匹配

3. **网络问题**
   - 检查服务器网络连接
   - 确认防火墙设置
   - 查看控制台错误日志

### Q: 如何自定义消息内容？
**A:** 修改 `/lib/feishu-webhook.ts` 文件：
```typescript
// 修改消息卡片内容
const message = {
  msg_type: 'interactive',
  card: {
    header: {
      title: {
        tag: 'plain_text',
        content: '🎯 新的客户预约'  // 修改标题
      },
      template: 'blue'  // 可选颜色: blue, green, red, yellow
    },
    // ... 其他内容
  }
}
```

### Q: 可以添加更多按钮吗？
**A:** 可以！在 `actions` 数组中添加：
```typescript
actions: [
  {
    tag: 'button',
    text: { tag: 'plain_text', content: '💬 立即联系' },
    url: `mailto:${formData.email}`,
    type: 'primary'
  },
  {
    tag: 'button', 
    text: { tag: 'plain_text', content: '📱 拨打电话' },
    url: `tel:${formData.phone}`,
    type: 'default'
  },
  {
    tag: 'button',
    text: { tag: 'plain_text', content: '📊 查看统计' },
    url: 'https://你的统计页面',
    type: 'default'
  }
]
```

### Q: 如何同时发送到多个群？
**A:** 创建多个机器人，在环境变量中配置：
```env
# 主要通知群
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/主要群地址

# 管理群（可选）
FEISHU_WEBHOOK_URL_ADMIN=https://open.feishu.cn/open-apis/bot/v2/hook/管理群地址
```

然后在代码中分别调用发送函数。

### Q: 可以设置免打扰时间吗？
**A:** 可以在代码中添加时间判断：
```typescript
const hour = new Date().getHours()
if (hour >= 9 && hour <= 18) {  // 工作时间：9:00-18:00
  await sendFormNotification(formData)
} else {
  console.log('非工作时间，跳过群通知')
}
```
